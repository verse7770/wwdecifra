# Wwdecifra

PROJETO: PLATAFORMA EDUCACIONAL INTELIGENTE — APROVA+



Quero que você desenvolva uma plataforma educacional completa, moderna, extremamente funcional e responsiva, voltada para estudantes brasileiros que estão se preparando para o ENEM, vestibulares, concursos públicos e outras provas importantes do Brasil.



O projeto deve funcionar como uma combinação de cursinho preparatório, professor particular com inteligência artificial, banco de questões, sistema de análise estatística de provas e planejador inteligente de estudos.



IMPORTANTE: Não quero apenas uma landing page bonita ou um protótipo visual. Quero uma aplicação real, com funcionalidades operacionais, banco de dados, autenticação, painel do estudante, sistema de questões, acompanhamento de desempenho e ferramentas de inteligência artificial.

3. SISTEMA DE ANÁLISE INTELIGENTE DE PROVAS



Esta será uma das funcionalidades mais importantes da plataforma.



Desenvolva um sistema que analise provas oficiais do ENEM e de outros vestibulares utilizando os dados dos últimos três anos.



Período inicial de análise:



- 2024. 

- 2025. 

- 2026. 



O sistema deverá considerar as provas, gabaritos, editais e questões efetivamente disponíveis.



Atenção: caso a prova ou os dados estatísticos de determinado ano ainda não estejam disponíveis, o sistema deverá indicar essa limitação. Nunca inventar questões, frequências ou estatísticas.



A análise deverá identificar:



1. Quais matérias aparecem com maior frequência.

2. Quais assuntos são mais cobrados.

3. Quais assuntos aparecem repetidamente.

4. Quais conteúdos ganharam ou perderam frequência.

5. Quais habilidades são mais exigidas.

6. Quais tipos de interpretação são recorrentes.

7. Quais conteúdos merecem maior prioridade.

8. Quais assuntos possuem maior incidência histórica.

9. Quais tendências podem ser observadas nas provas.

10. Quais conteúdos o estudante ainda precisa dominar.



Criar um sistema de classificação:



- Prioridade muito alta.

- Prioridade alta.

- Prioridade média.

- Prioridade baixa.



Cada classificação deverá apresentar uma justificativa baseada nos dados disponíveis.



Exemplo:



MATEMÁTICA — FUNÇÕES



Prioridade: Alta.



Justificativa:

Assunto identificado em diferentes edições das provas analisadas, com relevância para a resolução de questões envolvendo interpretação de gráficos, relações entre variáveis e problemas contextualizados.



IMPORTANTE: Diferenciar frequência histórica de previsão. A plataforma pode apontar assuntos com maior recorrência, mas nunca garantir que determinado conteúdo cairá na próxima prova.
